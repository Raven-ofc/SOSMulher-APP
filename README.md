(Para abrir e rodar o projeto é necessário possuir o SOS-Mulher-Web disponível no GitHub da raven e rodar ele com o php artisan serve --host=0.0.0.0)

Abra o seguinte link e copie a url do projeto https://github.com/Raven-ofc/SOSMulher-APP.git

Utilizando o git bash e o comando git clone, copie o repositório para a sua máquina

Ainda no git bash (ou no terminal) abra a pasta do sos-mulher-app e rode o comando 'npm install'

Se a instalação deu certo, utilize o comando code . no terminal, ou abra no seu editor de código a pasta do projeto.

No editor de código, troque todas as urls com 'seuip' para o ip da sua máquina (para descobrir rode ipconfig em qualquer terminal e copie o ipv4) 

No terminal do projeto rode npx expo start --go.

Leia o Qr code com um aparelho celular ou copie e cole o código 'exp://xxx.xxx.xx.x:8081' no campo do aplicativo expo go (sdk 54)

https://expo.dev/go?sdkVersion=54&platform=android&device=true
